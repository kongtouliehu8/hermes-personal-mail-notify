个人邮件提醒

Hermes Personal Mail Notify 是运行在所有者本机上的个人工具。它读取新到的 Gmail 收件箱邮件，生成简短中文摘要，再发到所有者预先指定的私人消息目标。

当前部署只服务于所有者自己的已授权邮箱，不开放注册，也不提供多人邮箱接入。本网站仅说明功能和数据处理方式，不收集 Google 密码或邮件内容。

邮件如何变成一条提醒

  1. Google Pub/Sub 通知本地程序邮箱发生了变化；程序用 Gmail API 补查新邮件。
  2. 本地队列记录消息标识和处理状态，避免在重启后重复提醒。
  3. 必要的发件信息和正文片段发送给已配置的 OpenAI 模型服务，用于判断重点和待办。
  4. 本地程序检查摘要后，经既有 Hermes / Photon / iMessage 通道发给所有者。

明确不会做的事

应用不会自动回复发件人、删除或归档邮件，也不会改变已读状态。它不下载附件来分析，不执行邮件里的命令，不让模型更改收件目标。需要处理的事项只作为提醒，不代表系统已经代为执行。

授权与运行

Google 授权在 Google 官方页面完成。应用使用 Gmail 只读权限、Pub/Sub 权限和识别授权账号所需的基本身份权限，不要求邮箱密码。后台依赖所有者的电脑、网络和所选服务；电脑休眠或授权失效时，提醒可能延迟。

这是独立的个人集成，不是 Google、OpenAI 或 Nous Research 的官方产品或官方支持服务。
